API de Cotação de Moedas

Esta API consulta cotações de moedas em tempo real, salva o histórico em banco de dados e calcula estatísticas (média, mínimo e máximo) a partir dos dados coletados.

Construída com FastAPI, SQLAlchemy e integração com a AwesomeAPI.

Ver documentação da API

Como consumir esta API

Basta fazer uma requisição GET para a rota abaixo, informando o código da moeda (ex: USD, EUR, GBP):

GET https://sua-api-no-render.onrender.com/cotacao/USD

Exemplo em Python, usando a biblioteca requests:

import requests

url = "https://sua-api-no-render.onrender.com/cotacao/USD"
resposta = requests.get(url)

print(resposta.json())

Há também uma rota de estatísticas, calculadas a partir do histórico já salvo para aquela moeda: 

GET https://sua-api-no-render.onrender.com/cotacao/USD/estatisticas
